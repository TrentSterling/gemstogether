# A01: Make hints show the swap

Started: 2026-10-20 20:54 UTC. Baseline: a611b47 (Gems Together 3.3.7).

Five real pointer-drag moves scored 750 during the initial playtest. Requesting
a hint highlighted two sockets, but the faint brackets did not explain the swap.
The chosen improvement is a compact double-ended mint arrow between those gems.
It uses the existing GPU vector renderer and projects the two board positions
each frame, including after phone rotation.

The cue remains static with Motion and Flashes off. It clears with the existing
hint lifecycle and is hidden during panels, photos, Showcase, completed runs and
active swaps. No scoring, move selection, timers, save keys, sound assets, room
namespaces or network packets change. The official name remains Gems Together.

## Reproduce

- `python tools/polish.py`
- `node tools/hint-audit.mjs` (seeded captures and real mouse/key/touch input)
- `node tools/hint-coop-audit.mjs` (local hints and synchronized peer swap)
- `node tools/verify.mjs`
- `node tools/expedition-audit.mjs`
- `node tools/expedition-visual.mjs`
- `node tools/clip.mjs index.html a01 hint 4`
- `node --test tests/about-contract.cjs`

Local release gates: hint geometry/lifecycle/input 52/52, normal gameplay 22/22,
progression/save/private co-op 48/48, both-backend mobile/keyboard/controller
visuals 112/112, About contracts 3/3. A separate diff and screenshot review
confirmed the generated HTML contains only the cue and version changes.

The release receipt and Library evidence bundle record final results, deployed
hashes, the immutable release commit and rollback reference. Screenshots and
clips are retained outside the published game in `tools/out` and Library.

Limitations: phone inputs use Chrome mobile emulation rather than a physical
handset; controller inputs use the existing emulated standard gamepad. The clip
uses deterministic frame stepping and contains no audio; it is not a performance
benchmark. This round does not rerun the historical speech/audio qualification.
